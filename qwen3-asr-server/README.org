#+TITLE: Qwen3-ASR-1.7B 本地语音转文字服务
#+subtitle: 自包含子项目 · llama.cpp(Metal) + Qwen3-ASR-1.7B · OpenAI 兼容接口
#+date: <2026-09-09>

* 这是什么

在 =llama.cpp= 上以 **Qwen3-ASR-1.7B** 为核心的中英语音转文字（ASR）服务，
提供一个 OpenAI 兼容的 =POST /v1/audio/transcriptions=。相比父项目（Fun-ASR-Nano
0.6B）：

- 引擎换成 Qwen3-ASR-1.7B（Q8_0），中英文识别质量明显更好，**不再需要**任何
  中英文“听错词→标准词”的字典映射。中文数字→阿拉伯数字（ITN-lite）的确定性
  规范仍保留，与旧版一致。
- 音频由 Qwen3-ASR 自身处理（不再外挂 SAN-M 编码器 + FSMN-VAD 二进制）。
- 保留“文本整理”层：口语填充词过滤、行首枚举编号、纯标点转写丢弃、段尾空行。

架构：前端 → Python 包装服务(:8011) → 常驻 llama-server(Metal, :8083) 原生
=llama.cpp= Qwen3-ASR 推理。

* 特性清单（保留 / 剔除）

保留：
- =POST /v1/audio/transcriptions=（multipart =file=）+ =GET /health=
- =organizer=：=rule=（默认）口语词清理+枚举编号；=none=（仅去引擎标记的原文）
- 中文数字→阿拉伯数字（ITN-lite，同旧版：三十五→35、百分之三十→30%、
  三点半→3点半；依赖 =pip install cn2an=，未装则原样输出）
- 纯标点/无正文转写 → 返回空
- 连续语音每段自动段尾空行
- Qwen3-ASR 输出前缀 =language …<asr_text>= 的剥离、=/sil= 清理（防御）

剔除（有意为之，Qwen3-ASR 不需要）：
- 指令词/专用词 别名→标准词 字典映射（父项目 =command_aliases.json=/=command_canon.py=）

* 快速开始

** 1. 编译 Metal 版 llama-server（一次）

#+BEGIN_SRC bash
./build-llama-server.sh --install   # 产物落在 .deps/llama.cpp/build 与 ./bin/
#+END_SRC
（=GGML_METAL=ON=，M 系芯片 GPU 加速；结果在 =bin/llama-server=。）

** 2. 下载模型（~2.5 GB）

#+BEGIN_SRC bash
./download-models.sh   # ggml-org/Qwen3-ASR-1.7B-GGUF 的 Q8_0 LLM + Q8_0 mmproj
#+END_SRC

** 3. 启动（后台常驻）

#+BEGIN_SRC bash
./start-server.sh
#+END_SRC
- 服务：=http://127.0.0.1:8011/v1/audio/transcriptions=，日志 =server.log=
- 引擎原生端点（裸转写、无整理层）：=http://127.0.0.1:8083/v1/audio/transcriptions=
- 改端口/档位：=QASR_PORT= QASR_ENGINE_PORT= QASR_ORGANIZER=none= 等（见脚本头注释）

验证：

#+BEGIN_SRC bash
curl -sf http://127.0.0.1:8011/health
curl http://127.0.0.1:8011/v1/audio/transcriptions -F file=@/tmp/x.wav
#+END_SRC

停止：再次运行脚本自动重启；或 =kill <start 输出里的两个 PID>=。

* 量化说明

- 默认 **Q8_0**（llama.cpp 官方量化，先跑通）。
- 5-bit（=Q5_K_M=）为后续步骤：=download-models.sh= 拉 =bf16= 版 LLM 后用
  =bin/llama-quantize= 压成 =Q5_K_M=；=mmproj= 保持官方 Q8_0。当前官方与社区
  GGUF 仓库均未发布 Q5，需自行量化。

* 目录结构

- =server/qwen3_asr_server.py= —— OpenAI 兼容 HTTP 包装 + 转发引擎
- =server/cleanup.py= —— 标记剥离 / 枚举编号 / 空转写门控 / 段尾空行
- =server/filler_filter.py= —— 口语填充词过滤（从父项目移植）
- =tests/= —— 单元 + 假引擎集成测试（=pytest qwen3-asr-server/tests=）

* 备注

- 常驻模式；模型加载一次。实测（M1 Pro + Metal/Q8_0）：~7s 中文语音
  **~0.5s**（含 Python 转发与清理层；引擎原生 ~0.9s），远低于纯 CPU 预期。
- 引擎返回自带 =language …<asr_text>= 前缀，包装服务已剥离后才进入清理管线。
- 英文指令词实测直出效果良好：=clear / org mode / Emacs= 均准确识别；
  =funasr= 偶被听成 =Funisir=（1.7B 已是明显进步；如仍在意可后续按需做极轻量
  白名单修正，本项目默认不做任何字典映射）。
